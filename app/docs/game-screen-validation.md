# ゲーム画面の実装・検証

2026-10-18（日本時間）時点。

## 実装した範囲

- openingの仮画面、AR調査、endingの選択・正誤判定、クリア表示。
- ホストによる2人同時の開始と、全証拠収集による自動ending移行。
- 同じARViewを保持した9:16 / 1:1切り替え、撮影、キャンセル、証拠モーダル、自己・合計カウント。
- RealityKitのComponent / Systemによる分類別の順次配置、認識面の範囲と中心間1mの検証。
- 札本体の表面まで30cmの判定、画面外・距離超過・追跡中断による選択解除。
- 約10cmの証拠名付き札、UIを含まないAR写真、端末内保存、最新写真への置き換え。
- ホスト確定の共有状態、操作の担当・フェーズ検証、収集重複の排除。
- 同じ相手との再接続、確定状態との照合、未確認の収集・提出の再送、写真の保持。
- endingの試行番号による古い提出の排除、誤答時の人物・両者の証拠リセット。

台詞・ストーリー演出、村人との会話、実モデルへの差し替え、アプリ終了後の復元は後回し。

## 実機2台で残る確認

1. 同じビルドを2台へ入れ、ホストがエピソードを選択。接続・状態同期後に開始でき、ゲストもopeningへ進むこと。
2. ホスト操作で2人がAR調査へ進み、ホストに人的証拠、ゲストに物的証拠だけが配置されること。
3. Wallと認識されるまで配置されず、狭い面・面の更新でも札全体の包含と中心間1mが保たれること。
4. 撮影画面が1:1になり、画面内の札の表面まで30cm以内でタップした場合だけシャッターが有効になること。離れる・画面外に出る・追跡中断で解除されること。
5. 保存写真がカメラ映像とAR札を含み、操作UIを含まないこと。撮影後は探索へ戻り、札が残り、再撮影で写真だけが置き換わること。
6. 証拠モーダルには自分の撮影済み証拠だけが表示され、自己・合計カウントが両端末で一致すること。
7. 途中で通信を切断し、操作が止まること。同じ相手に復帰すると写真・配置・フェーズ・未確認操作が保持されること。
8. 最後の証拠をほぼ同時に撮影した場合や、証拠モーダルが開いている場合も、2人がendingへ移行すること。
9. ホストの人物確定後に各自が証拠を提示できること。誤答で両者リセット、正答で両者クリア、各自がタイトルへ戻れること。

ARの配置精度・距離精度と2台間の実通信は未検証。ビルド・自動テストの成功とは分けて扱う。
